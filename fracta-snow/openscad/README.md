# OpenSCAD files

## Files
- `fracta_snow.scad` — first draft parametric model scaffold for the Fracta Snow pendant

## Current modeling approach
The first draft uses a recursive 2D Koch snowflake outline and stacks multiple scaled layers vertically to create a lantern-like pendant shade.

## What is implemented
- recursive snowflake edge generation
- stacked shade layers
- central socket opening
- simple bulb clearance preview
- provisional top mounting disc

## What still needs work
- actual IKEA hardware dimensions
- better top attachment and strain relief details
- improved shade-to-socket mounting strategy
- lower opening / bulb access refinement
- optional ribbed or lofted variants
