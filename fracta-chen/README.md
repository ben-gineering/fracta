# Fracta Chen

Fracta Chen is a geometry study inspired directly by the Chen chaotic attractor and its double-scroll trajectory structure.

## Concept
A thickened sampled Chen attractor path, forming two dense lobes joined by a narrower transition waist.

## Goals
- Build in OpenSCAD
- Use BOSL2 where useful
- Preserve the recognizable twin-lobed Chen attractor silhouette
- Study the spatial character of the attractor before turning it into a lamp
