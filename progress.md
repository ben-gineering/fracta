## Working method going forward
For each remaining lamp:
1. Define and refine the concept direction
2. Create OpenSCAD scaffold and notes
3. Build a first draft parametric model
4. Generate render set from command line:
   - isometric view
   - front orthographic
   - side orthographic
   - top orthographic
5. Review the visuals critically
6. Refine geometry iteratively
7. Commit each meaningful iteration to git
8. Document the chosen direction in the lamp folder

## Design quality bar
- Strong silhouette in at least iso, front, side, and top views
- Clear fractal inspiration without becoming arbitrary
- Manufacturable parametric structure
- Compatible with IKEA-style bulb/socket/cable hardware assumptions
- Cohesive relation to the Fracta series
