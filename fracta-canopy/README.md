# Fracta Canopy

Fracta Canopy is a pendant lamp concept inspired by branching tree canopies and nested structural shelter forms.

## Concept
A dome-like pendant with branching ribs spreading from a top hub toward a wider lower perimeter. The form should feel calm, architectural, and warm.

## Design goals
- Build in OpenSCAD
- Use BOSL2 where useful
- Design around IKEA-standard bulb, socket, and cable hardware
- Create a readable canopy silhouette from multiple views
- Keep the branching logic structured, not random
