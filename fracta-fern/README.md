# Fracta Fern

Fracta Fern is an organic lamp concept in the Fracta series, inspired by fern fronds, recursive branching, and botanical self-similarity.

## Concept
A pendant or table-oriented shade made from a central stem and repeated branchlets that radiate outward like layered fern growth. The structure should feel elegant, natural, and designed rather than random.

## Design goals
- Build in OpenSCAD
- Use BOSL2 for transforms and reusable geometry helpers where useful
- Design around IKEA-standard bulb, socket, and cable hardware
- Create a calm, botanical silhouette with rich shadow play
- Keep the branching structure parametric and printable

## Product direction
- Primary type: pendant lamp
- Style: organic, refined, airy
- Light quality: broken, leafy shadow patterns
- Construction: central core with repeated branching ribs

## Proposed hardware assumptions
- Socket type: E27 pendant socket
- Cable: standard hanging cord set
- Mounting: central top mount with bulb cavity below
